Para la correcta ejecución de este proyecto, es necesario tener el JDK 23.

En caso de registrarse utilizando la opción de cuenta IUPM (UPMAuthenticator), si se introduce un correo con el dominio @upm.es se creará una cuenta tipo "PersonalUPM", mientras que si se introduce un correo con el dominio @alumnos.upm.es se creará una cuenta de tipo "EstudianteUPM".
Si se registra con un correo electrónico extrno a la universidad se crea una cuenta de tipo "ParticipanteExterno".

En el fichero usuarios.txt (en la carpeta principal) se guardan los usuarios creados.

Hemos creado para las pruebas un administrador, que inicia sesión con el correo: "administradoe@upm.es" y contraseña: "Administrador1234"
Para probar un usuario que sea EstudianteUPM hemos creado un usuario que inicia sesión con el correo "estudiante@upm.es" y contraseña "Estudiante1234"
Un PersonalUPM que inicia con correo "personal@upm.es" y contraseña "PersonalUPM1234"
Un participante externo que inicia sesión con el correo "participanteexterno@gmail.com" y la contraseña "ParticipanteExterno1234"
